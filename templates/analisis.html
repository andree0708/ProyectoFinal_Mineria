Contexto

Un conjunto de datos equilibrado

Sentiment140 contiene {{ d.n_tweets|miles }} tweets de {{ d.n_usuarios|miles }} usuarios, con la misma cantidad de mensajes positivos y negativos. Por eso la accuracy es una medida representativa: un clasificador que respondiera al azar acertaría alrededor del 50 %. Los mensajes son breves, con unas {{ d.palabras_media.negativo|round|int }} palabras de media.

Las etiquetas se asignaron automáticamente a partir de los emoticonos de cada mensaje, que después se eliminaron del texto. Este método introduce cierto margen de error en las etiquetas, por lo que los resultados habituales con modelos clásicos se sitúan entre el 75 % y el 80 % de accuracy.

Este cambio se debe a la forma en que se construyó el dataset. Las comparaciones entre fechas anteriores al {{ st.corte|fecha(0, false) }} sirven como referencia; los días posteriores no representan la opinión de ese periodo.

Conservar las negaciones mejora la clasificación

Expresiones como "not good" o "don't like" invierten el sentido de una frase. En el preprocesamiento habitual estas palabras se descartan por ser muy frecuentes, y "not good" se analiza como "good". Sentinel las conserva.

Para medir el efecto, se entrenó {{ ng.modelo }} con y sin este tratamiento. El {{ ng.pct_tweets_con_negacion|pct(0) }} de los tweets contiene alguna negación, y en ellos la accuracy pasa del {{ ng.antes.accuracy_con|pct }} al {{ ng.despues.accuracy_con|pct }}. En el total de la muestra, del {{ ng.antes.accuracy|pct }} al {{ ng.despues.accuracy|pct }}.

Conclusiones

Recomendación

{% if empate %}Naive Bayes y SVM ofrecen{% else %}{{ best }} ofrece{% endif %} el mejor equilibrio entre precisión y coste, con una accuracy cercana al {{ M[best].accuracy|pct(0) }} en el conjunto general{% if a.manual %} y del {{ a.manual.modelos[best].accuracy|pct(0) }} en tweets etiquetados por personas{% endif %}. {% if cons_sig %}La votación entre los tres modelos aporta una mejora adicional.{% endif %} Random Forest, por sí solo, no compensa su mayor coste.

Limitaciones

  • Etiquetas asignadas automáticamente y sin clase neutral
  • Tweets en inglés, publicados en 2009
  • Distribución temporal condicionada por la recolección
  • Resultados por marca aproximados cuando hay pocos tweets
